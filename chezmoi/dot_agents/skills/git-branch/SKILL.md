# Gitブランチ作成

1. `git status --short`、`git branch --show-current`、必要な差分を確認する。
2. ユーザー指定の名前・`--from` / `--base` を優先する。名前の指定がなければ `feat/`、`fix/`、`chore/` 等と英小文字・ハイフンで目的を表す短い名前を選ぶ。通常の命名だけで確認を挟まない。
3. ベース指定がなければ現在の `HEAD` から作成し、その旨を伝える。未コミット変更はそのまま保持する。自動で stash・コミット・破棄しない。
4. `git check-ref-format --branch <name>` と既存ブランチを確認し、`git switch -c <name>` を実行する。ベースが指定されていれば末尾にその参照を渡す。既存ブランチを上書きしない。指定ベースが不明、または切り替えが差分と衝突する場合は停止して状況を伝える。
5. 作成後にブランチ名と `git status --short` を確認し、作成名、作成元、既存差分を保持したことを簡潔に報告する。

引数はシェル用にクォートする。ブランチ作成の依頼だけで push やPR作成は行わない。
