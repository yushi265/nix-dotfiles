# Note Skill

## 概要

このスキルは、**今の会話セッションの内容を振り返って要約し**、Obsidian vaultの `20_Notes/` に新規ノートとして保存する。

このマシンには `logging-tool` プラグインが別途動いており、セッションの生ログ全文を自動的に `80_ClaudeSessions/<project>/` に書き出している（フルトランスクリプト、自動・バックグラウンド）。それに対してこのスキルは、**ユーザーが明示的に呼んだときだけ**、あとで読み返して要点がすぐわかる「まとめノート」を作ることが目的。生ログの方には一切手を触れない。

Vaultのパス: `/Users/shina/src/github.com/yushi265/digital-garden`（GHQ管理下）。パスが見つからない・vault構造が変わっている場合は憶測で進めずユーザーに確認する。

## ステップ1: 引数解析

- 引数なし: このセッション全体を対象に要約する
- キーワード・話題を指定された場合（例:「認証まわりだけまとめて」）: セッション内の該当部分に絞って要約する

## ステップ2: セッション内容の振り返り

会話全体（このスキル呼び出しより前のやり取り全部）を振り返り、以下の観点で整理する。空振りした試行錯誤や単純な確認応答は削り、後で読んで意味が通る粒度に圧縮する。

- **目的・きっかけ**: 何を頼まれた/何から始まったか
- **やったこと・変更点**: 具体的な成果物（ファイルパス、コマンド、作成したスキルや設定など）
- **決定事項とその理由**: 複数の選択肢があった場合、何を選びなぜか（トレードオフ含む）
- **未解決・保留事項**: 確認待ち、あとで対応が必要なもの
- **次のアクション**: あれば

## ステップ3: トピックタグの判定

`inbox-tidy` スキルと同じ語彙を使う。複数該当すればすべて付ける。

| タグ | 範囲 |
|------|------|
| `tech` | 技術・開発・プログラミング・ツール・スキル作成など |
| `money` | お金・税金・保険・投資・各種手続き |
| `life` | 暮らし・買い物・旅行・趣味・雑事 |
| `health` | 健康・筋トレ・食事・睡眠 |
| `idea` | アイデア・方法論・考察・思索メモ |

どれにも当てはまらない場合は、内容に即した新しいタグ（小文字英語）を提案し、進めてよいか確認せずそのまま採用してよい（vaultの他ノートにも独自タグは存在する）。

## ステップ4: タイトル・ファイル名の決定

内容を一言で表す簡潔な日本語タイトルを決める（例:「session-noteスキルの作成」）。

```
!`ls 20_Notes/*.md 2>/dev/null`
```

既存ファイルと同名になる場合は、末尾に日付を付けるなどして重複を避ける。

## ステップ5: ノート作成

`20_Notes/<タイトル>.md` を新規作成する。フロントマターは vault の既存ノート（`20_Notes/2026-04-21.md` 等）と同じ形式に合わせる。

```markdown
---
created: YYYY-MM-DD
tags:
  - tech
updated: YYYY-MM-DDTHH:mm
---

# <タイトル>

## 目的
...

## やったこと
- ...

## 決定事項
- ...（理由も添える）

## 未解決・次のアクション
- ...
```

`created`/`updated` は現在日時を `date` コマンド等で取得して埋める。未解決・次のアクションが無ければそのセクションごと省略してよい。

## ステップ6: 結果報告

作成したノートのパスと、付与したタグ、タイトルを報告する。

```
✅ セッションノート作成完了
- 📄 20_Notes/<タイトル>.md
- 🏷 タグ: tech
```

vaultは obsidian-git が自動コミットするため、追加のgit操作は不要である旨も添える。

## 注意事項

- 生ログ全文（`80_ClaudeSessions/`）には触れない・重複転記しない。あくまで要約に徹する
- 確定していない解釈（タイトル案・タグ判定に迷うケース）は憶測で進めず、簡潔にユーザーへ確認する
- 既存の日本語表記・Obsidian記法（フロントマター形式など）を壊さない
