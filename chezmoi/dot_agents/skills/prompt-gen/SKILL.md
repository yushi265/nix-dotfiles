# プロンプト作成

今回の依頼や会話で指定された内容をもとに、目的、対象、制約、期待する出力を整理する。入力がなく会話からも特定できなければ、利用可能な質問手段で内容を尋ねる。

プロンプトはそのまま使える完成形で提示する。単純な依頼なら短い文章、複雑な依頼なら必要な見出しだけ使う。背景や品質基準は役立つ場合に含める。指定されていない技術、作業範囲、権限を勝手に追加しない。出力言語はユーザーの指定を優先する。

文案を作るだけのために承認ループを設けない。修正が届いたら反映する。

コピーも依頼されている場合は、利用可能なクリップボード機能を使う。macOSでは生成文を一時UTF-8ファイルに保存して `pbcopy < <一時ファイルのパス>` で渡せる。生成文をシェルやPythonコードに埋め込まない。成功時のみコピー完了を報告し、利用できなければ本文を提示してその旨を伝える。
