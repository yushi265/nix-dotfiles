# Prompt Generation Skill

## 概要

ユーザーのラフな入力テキストを、AI Agent / 生成AIへの依頼に適した構造化プロンプトに変換し、クリップボードにコピーする。

## ステップ1: 入力テキストの受け取り

`$ARGUMENTS` からユーザーの入力テキストを取得する。

入力が空の場合は `AskUserQuestion` でプロンプト化したい内容を聞く:

```
プロンプト化したい内容を教えてください。
（例: Pythonでスクレイピングスクリプトを作ってほしい、会議の議事録を整理してほしい、など）
```

## ステップ2: 入力テキストの分析

入力テキストを読み取り、以下の要素を特定する:

| 要素 | 内容 |
|------|------|
| **タスクの種類** | コード生成 / 文章作成 / 分析 / 質問回答 / リファクタリング / デバッグ / その他 |
| **対象** | 何に対する作業か（言語、ファイル、概念など） |
| **制約・条件** | 言語指定、フォーマット、スタイル、制限事項 |
| **期待する出力** | どんな形式・内容の出力が欲しいか |

## ステップ3: 構造化プロンプトの生成

分析結果をもとに以下のテンプレートでプロンプトを生成する。**セクションは内容に応じて取捨選択**する。

```markdown
## 役割
[このタスクに最適なAIの振る舞いを定義]

## コンテキスト
[背景情報、前提条件]

## タスク
[具体的にやってほしいことを明確に記述]

## 制約条件
- [守るべきルール1]
- [守るべきルール2]

## 出力形式
[期待する出力のフォーマットや構造]

## 品質基準
- [満たすべき品質基準]
```

### 生成ルール

- **シンプルな入力** → セクションを最小限にする（過度な構造化を避ける）
- **複雑・曖昧な入力** → 明確化のためにセクションを充実させる
- 元の入力の意図を変えない。補強・明確化のみ行う
- 日本語の入力には日本語で、英語の入力には英語でプロンプトを生成する

## ステップ4: ユーザーへの確認

生成したプロンプトをそのままテキストとして表示（コードブロックなし）し、`AskUserQuestion` で確認する:

- 選択肢1: **このままコピー**（推奨）
- 選択肢2: **修正してからコピー**（フィードバックを入力）

修正が選ばれた場合は、フィードバックを反映してプロンプトを再生成し、再度確認する（このループを確定まで繰り返す）。

## ステップ5: クリップボードへのコピー

確定したプロンプトを `pbcopy` でクリップボードにコピーする:

```bash
python3 -c "import subprocess; subprocess.run(['pbcopy'], input='''<確定したプロンプト>'''.encode())"
```

または:

```bash
printf '%s' '<確定したプロンプト>' | pbcopy
```

コピー完了をユーザーに報告する:

```
クリップボードにコピーしました。そのまま貼り付けて使えます。
```
